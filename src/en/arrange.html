Tool 01 · Photo layout

Print multiple photos on one page.

Build an A4 or Letter photo grid without a design app. Choose your pictures, adjust the order and copies, then preview every sheet before downloading.

1 Choose images · 2 Edit and set sizes · 3 Preview and download PDF

1. Images

Choose Edit image to crop, rotate or change pixel dimensions.

Supported files and limits

JPG, PNG and WebP. Up to 30 images, 20 MiB per file and 12 megapixels per image. Total originals and edits: 32 megapixels and 80 MiB. Decoded pixels alone may use 128 MB, plus preview and export memory. Maximum 30 PDF pages.

    2. Size and layout

    In Individual print sizes mode, set each frame on its image card. Photos are packed in order without overlapping.

    Short guide and examples

    How do I arrange photos?

    Add images, then drag their cards or use Move up and Move down. Equal grid uses rows and columns. Individual print sizes lets you set each frame in millimeters; another page is added when the available space is full.

    How do I change image size?

    For dimensions on paper, use the width and height fields in Individual print sizes mode. For pixel dimensions, cropping or rotation, choose Edit image. Download the edited PNG or apply it to your print layout.

    Quick example

    For six photos on A4, choose two columns and three rows. For two photos each 8 cm wide, use individual sizes and set each card width to 80 mm. Set Copies to repeat a photo.
