# رتّب واطبع

موقع ثابت بالعربية افتراضيًا واتجاه RTL، مع نسخة إنجليزية كاملة باتجاه LTR تحت /en/. الاسم العربي «رتّب واطبع» والإنجليزي Arrange & Print. المعالجة محلية، دون رفع صور أو Backend أو حسابات مستخدمين. الأدوات مجانية، والإعلانات معطلة افتراضيًا.

## التشغيل

يتطلب Node.js 22 أو أحدث، وPython 3. لا يلزم مفتاح أو سر.

```sh
npm ci
npm run build
npm start
```

يخدم الأمر الأخير `dist` على المنفذ 8080. المصدر في `src/`، وحسابات التخطيط في `src/assets/layout.js`، والتصدير داخل Web Worker يمكن إنهاؤه عند الإلغاء. البناء يعيد توليد صفحات HTML من `scripts/pages-ar.mjs` و`scripts/pages-en.mjs` عبر `scripts/pages.mjs`، ثم ينسخها إلى dist. عدّل قوالب اللغة بدل HTML المولّد حتى لا تُفقد تعديلاتك عند البناء. تترجم `src/assets/i18n.js` رسائل الأدوات المشتركة.

`site.config.json` مصدر إعداد اسم الموقع وعنوانه وبريده ومعرف AdSense. بعد تعديل أي مصدر أو إعداد شغّل `npm run build` لتحديث dist وZIP معًا. المكتبة pdf-lib مثبتة عند 1.17.1 في package-lock.json، وتُنسخ محليًا مع ترخيصها وتراخيص تبعياتها المضمّنة. لا حاجة لـCDN عند الاستخدام.

## الاختبارات

```sh
npm test
```

الاختبار يستخدم Chromium من `/usr/bin/chromium`؛ يمكن تعيين `CHROMIUM_PATH` لمسار آخر. يشغّل خادمًا محليًا للاختبار ثم يغلقه. يتحقق من التنقل وواجهة الهاتف وملف تالف والترتيب والنسخ والإلغاء وتصدير PDF الفعلي. يفحص أحجام الصفحات وعددها وعوامل رسم الصور والقص وحدود الهوامش والمقاس الصحيح. لا يختبر طابعة مادية أو خدمات Google.

توجد نتيجة التنفيذ الفعلي في `TEST_REPORT_AR.md`. ملفات الاختبارات والتوثيق وnode_modules خارج ZIP.

## حدود المعالجة

30 صورة كحد أقصى، 20 MiB للملف، 12 مليون بكسل للصورة، 32 مليون بكسل إجمالًا، و80 MiB للصور بعد توحيدها إلى PNG. قد يستخدم المتصفح عدة نسخ مؤقتة أثناء فك الصور والتصدير؛ حد البكسلات ليس ضمانًا لذاكرة فعلية مقدارها 128 MB. لاختيار آمن على هاتف ضعيف استخدم صورًا أصغر وعددًا أقل. حتى 30 صفحة و5×5 للبوستر. لا تحسين اصطناعي للدقة ولا تمديد؛ القص مركزي.

اتجاه EXIF يُعالج عند فك الصورة عبر createImageBitmap مع from-image. PNG/WebP يُحوّلان محليًا إلى PNG مع الحفاظ على الشفافية. الطباعة على بياض الورقة، ولا توجد إدارة ألوان احترافية أو ضمان للمظهر النهائي. المعاينة بحجم مخفّض لكن التصدير يستخدم الصورة المقبولة بدقتها الكاملة. الخط المتقطع في أداة المقاس لا يُصدّر.

الصور في ذاكرة الصفحة فقط. حفظ تفضيلات الطباعة اختياري في LocalStorage مع زر مسح. PDF ينزله المستخدم إلى جهازه. التصدير Worker محلي؛ الإلغاء ينهيه، وقد يتأخر إلغاء فك صورة حتى انتهاء عملية فك المتصفح الحالية.

## البيئة السحابية

استخدم النسخة الموجودة `/workspace/website-1`؛ كل مهمة معزولة أصلًا ولا تنشئ Git worktree دون طلب صريح. الإعداد المتكرر: `npm ci` ثم `npm run build` ثم `npm test`. بدء الخدمة `npm start`، والتحقق بطلب index.html والأدوات. لا يلزم نشر خارجي للعمل المحلي.


## اللغات

العربية في جذر الموقع، والإنجليزية تحت /en/. رابط التبديل في أعلى كل صفحة ينقل إلى نظيرتها باللغة الأخرى. التبديل يعيد فتح الصفحة؛ الصور لا تنتقل ولا تحفظ بين الصفحات، لذا اخترها مجددًا. تفضيلات الطباعة المحفوظة اختياريًا مشتركة بين اللغتين. لكل نسخة عنوان ووصف وcanonical مستقل، وروابط hreflang متبادلة. يحتوي sitemap على 26 صفحة قابلة للفهرسة؛ صفحتا 404 غير قابلتين للفهرسة. أسماء العلامة المركزية في siteName وsiteNameAr داخل site.config.json.
