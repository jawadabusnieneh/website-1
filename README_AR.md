# رتّب واطبع

موقع ثابت بالعربية افتراضيًا واتجاه RTL، مع نسخة إنجليزية كاملة باتجاه LTR تحت /en/. الاسم العربي «رتّب واطبع» والإنجليزي Arrange & Print. المعالجة محلية، دون رفع صور أو Backend أو حسابات مستخدمين. الأدوات مجانية. كود Google AdSense مفعّل حاليًا في الصفحة الرئيسية وصفحات المحتوى فقط، بعد إفادة المالك بأن الموقع جاهز ورسالة الموافقة منشورة؛ يُستثنى من أدوات الصور واختبار الطباعة وصفحات الخطأ.

## التشغيل

يتطلب Node.js 22 أو أحدث، وPython 3. لا يلزم مفتاح أو سر.

```sh
npm ci
npm run build
npm start
```

يخدم الأمر الأخير `dist` على المنفذ 8080. المصدر في `src/`، وحسابات التخطيط في `src/assets/layout.js`، والتصدير داخل Web Worker يمكن إنهاؤه عند الإلغاء. البناء يعيد توليد صفحات HTML من `scripts/pages-ar.mjs` و`scripts/pages-en.mjs` عبر `scripts/pages.mjs`، ثم ينسخها إلى dist. عدّل قوالب اللغة بدل HTML المولّد حتى لا تُفقد تعديلاتك عند البناء. تُبنى واجهة الأدوات وشرحها المختصر من `scripts/tool-ui.mjs` وتترجم `src/assets/i18n.js` رسائل الأدوات المشتركة. محرر الصور في `src/assets/editor.js` وعمليات البكسلات في `src/assets/image-edit.js`.

`site.config.json` مصدر إعداد اسم الموقع وعنوانه وبريده ومعرف AdSense. بعد تعديل أي مصدر أو إعداد شغّل `npm run build` لتحديث dist وZIP معًا. المكتبة pdf-lib مثبتة عند 1.17.1 في package-lock.json، وتُنسخ محليًا مع ترخيصها وتراخيص تبعياتها المضمّنة. لا حاجة لـCDN عند الاستخدام.

## الاختبارات

```sh
npm test
```

الاختبار يستخدم Chromium من `/usr/bin/chromium`؛ يمكن تعيين `CHROMIUM_PATH` لمسار آخر. يشغّل خادمًا محليًا للاختبار ثم يغلقه. يتحقق من التنقل وواجهة الهاتف وملف تالف والترتيب والنسخ والإلغاء وتصدير PDF الفعلي. يفحص أحجام الصفحات وعددها وعوامل رسم الصور والقص وحدود الهوامش والمقاس الصحيح. لا يختبر طابعة مادية أو عرض إعلانات Google فعليًا. يعترض سكربت AdSense الرسمي ويرد بسكربت فارغ أثناء الاختبار، ويفحص رابط السكربت ووجوده مرة واحدة في الصفحات المسموحة وعدم وجوده في الأدوات والطباعة.

توجد نتيجة التنفيذ الفعلي في `TEST_REPORT_AR.md`. ملفات الاختبارات والتوثيق وnode_modules خارج ZIP.

## حدود المعالجة

30 صورة كحد أقصى، 20 MiB للملف، 12 مليون بكسل للصورة، 32 مليون بكسل إجمالًا و80 MiB للصور الموحّدة، مع احتساب النسخ الأصلية والمعدّلة المحتفظ بها أثناء الجلسة. قد يستخدم المتصفح عدة نسخ مؤقتة أثناء فك الصور والتصدير؛ حد البكسلات ليس ضمانًا لذاكرة فعلية مقدارها 128 MB. لاختيار آمن على هاتف ضعيف استخدم صورًا أصغر وعددًا أقل. حتى 30 صفحة و5×5 للبوستر. لا تحسين اصطناعي للدقة ولا تمديد. قص الإطار مركزي، ويمكن اختيار القص مسبقًا في المحرر. تغيير أبعاد الملف محصور في 8192 بكسل للضلع و12 مليون بكسل للصورة المعدلة.

اتجاه EXIF يُعالج عند فك الصورة عبر createImageBitmap مع from-image. PNG/WebP يُحوّلان محليًا إلى PNG مع الحفاظ على الشفافية. الطباعة على بياض الورقة، ولا توجد إدارة ألوان احترافية أو ضمان للمظهر النهائي. المعاينة بحجم مخفّض لكن التصدير يستخدم الصورة المقبولة بدقتها الكاملة. الخط المتقطع في أداة المقاس لا يُصدّر.

الصور في ذاكرة الصفحة فقط. حفظ تفضيلات الطباعة اختياري في LocalStorage مع زر مسح. PDF ينزله المستخدم إلى جهازه. التصدير Worker محلي؛ الإلغاء ينهيه، وقد يتأخر إلغاء فك صورة حتى انتهاء عملية فك المتصفح الحالية.

## البيئة السحابية

استخدم النسخة الموجودة `/workspace/website-1`؛ كل مهمة معزولة أصلًا ولا تنشئ Git worktree دون طلب صريح. الإعداد المتكرر: `npm ci` ثم `npm run build` ثم `npm test`. بدء الخدمة `npm start`، والتحقق بطلب index.html والأدوات. لا يلزم نشر خارجي للعمل المحلي.


## اللغات

العربية في جذر الموقع، والإنجليزية تحت /en/. رابط التبديل في أعلى كل صفحة ينقل إلى نظيرتها باللغة الأخرى. التبديل يعيد فتح الصفحة؛ الصور لا تنتقل ولا تحفظ بين الصفحات، لذا اخترها مجددًا. تفضيلات الطباعة المحفوظة اختياريًا مشتركة بين اللغتين. لكل نسخة عنوان ووصف وcanonical مستقل، وروابط hreflang متبادلة. يحتوي sitemap على 26 صفحة قابلة للفهرسة؛ صفحتا 404 غير قابلتين للفهرسة. أسماء العلامة المركزية في siteName وsiteNameAr داخل site.config.json.


## أدوات التحرير والمقاسات

- اضغط «تعديل الصورة» على أي بطاقة لفتح محرر محلي. اختر نسبة قص جاهزة أو حدّد القص بنسب مئوية من الأصل، ثم دوّر الصورة أو اعكسها أفقيًا. الأبعاد بالبكسل مترابطة دائمًا لمنع التمديد. «تنزيل PNG» يحفظ مسودة التعديل دون تطبيقها على الطباعة، و«تطبيق التعديل» يستبدل النسخة المستخدمة في المعاينة وPDF. الإغلاق أو Escape يلغي المسودة، و«استعادة الأصل» يعيد الأصل داخل المحرر ويتطلب التطبيق لتغيير ملف الطباعة.
- في ترتيب الصور، يوزّع وضع «شبكة متساوية» الصور في خانات متساوية. وضع «مقاس خاص لكل صورة» يتيح عرضًا وارتفاعًا بالمليمتر لكل بطاقة، مع ربط اختياري بالنسبة الأصلية، وتوزيع على صفوف وصفحات دون تداخل. إذا أُلغيت الرابطة، فالحقول تحدد الإطار؛ الاحتواء/القص يحافظ على نسبة الصورة دون تمديد.
- في أداة المقاس المحدد، توجد قوالب 10×15 و13×18 سم و4×6 و5×7 بوصة ومربع. تغيير الوحدة يحافظ على المقاس الفعلي. ربط الأبعاد بنسبة الصورة اختياري. القالب يضبط الإطار؛ راجع الاحتواء والقص قبل التنزيل.
- في البوستر، يمكن احتواء الصورة كاملة بدل قص الأطراف. يوضّح الملخص مقاس منطقة الصورة بعد تجميع الأوراق والتداخل.

المحرر ليس معالجة بالخادم ولا يكتب فوق الملف الأصلي في جهاز المستخدم. يحتفظ بالأصل في ذاكرة الصفحة لاستعادة التعديلات؛ يفشل التطبيق برسالة واضحة إذا تجاوزت الأصول والتعديلات ميزانية البكسلات أو البيانات. قد يتطلب إنشاء Canvas أو PNG وقتًا غير قابل للمقاطعة فورًا داخل المتصفح. تظل اختبارات الطابعة الفعلية والألوان وSafari على جهاز حقيقي غير منفّذة.
